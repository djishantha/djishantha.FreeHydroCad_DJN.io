HYPACK XYZ VDATUM Z Adjuster

Match every survey XYZ point to the closest VDATUM XY point and calculate the adjusted Z value.

1. Select VDATUM XYZ File

No VDATUM file selected
Select the VDATUM XYZ file containing X, Y and Z values.

2. Select Survey / Second XYZ File

No survey file selected
X and Y from this file will be retained. The Z value will be adjusted using the closest VDATUM point.

Calculation

New Z = Survey Z + VDATUM Z
For every point in the survey file, the program finds the VDATUM point with the closest X and Y location.
Example:

Survey Z = 8.30
VDATUM Z = -0.71

New Z = 8.30 + (-0.71) = 7.59
0%
Select both files to begin.
