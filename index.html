A point of a later file is an overlap when it lies within the overlap distance of a point of the first file. By default the distance is the average spacing between neighbouring points of the first file (the average closest-point distance), so it adapts to the survey density. Overlapping points of the later file are removed, and the first file's XY coordinates are never changed. Each first-file point that has a later-file point within that distance takes: 1. the shallower Z (closest to zero) of the two points, 2. the average Z of the two points, or 3. the later file's Z. Later-file points outside the overlap are kept.

How to get the best result

Use the free Google Earth Pro desktop program, not Google Maps or the web page.

A. Set up the view

  1. Go to your site and zoom until the area fills the screen.
  2. Press U to look straight down and N for north up.
  3. In Layers, untick 3D Buildings, Borders and Labels, Roads and other overlays. Keep your own placemarks on.
  4. Tools → Options → 3D View: lowest Terrain Quality (or untick Terrain). Tools → Options → Navigation: Do not automatically tilt while zooming.

B. The placemarks (control points)

  1. Add 5 to 10 placemarks (more is better, 3 is the minimum). Put them on sharp, easy-to-see features whose real coordinates you know (pier corners, survey marks), spread over the area and close to the part you need most. Zoom in close and put the pin tip exactly on the feature.
  2. Double-click a placemark to open its properties and give it a name: A, B, C…
  3. Altitude tab: do not choose Clamped to ground or Clamped to sea floor. Choose Relative to ground (or relative to sea floor) or Absolute.
  4. Put all the placemarks in one folder, right-click the folder → Save Place As… → KMZ. Save it now, while the placemarks still have their names.

C. Last: save the picture

  1. Style, Color tab → Label: set Scale to 0 so no letters appear in the picture (the names stay in the KMZ you already saved). Keep a simple flat icon (the default white pin is good) with scale 1.
  2. File → Save → Save Image. Hide the title, legend, scale and compass, and choose the highest resolution. Do not move the view before saving.

D. In this page

  1. Choose the picture.
  2. Choose the KMZ: the names and coordinates fill in. If you have real (survey) coordinates for the same features, type them over the ones from the file and pick the right coordinate type.
  3. Click Find pins in picture. Pins that are not found: click Pick, then click the pin tip on the picture. Use the Zoom box (up to 8×) for exact clicks.
  4. Look at the Error column. A number in red means that point is probably wrong (tip not on the feature, or wrong coordinate). Fix it and run again.
  5. Keep Rotate + scale + shift only for a picture that must keep its shape. Choose the output system and click Georeference.
  6. Leave Remove the placemark icons… ticked to clean the markers from the saved picture, then download.
Smaller areas = less distortion. For a big site, take several overlapping pictures.
Check it: compare a known distance in the result with the real distance. Google imagery itself can be several metres off, so real survey coordinates on the pins matter.

Combine images

Join several georeferenced pictures (for example the GeoTIFFs made in GeoRef Google Image) into one image. Choose all the files together: GeoTIFFs with embedded coordinates, or JPG / PNG / TIFF pictures together with their world files (.tfw, .jgw, .pgw, .j2w, .wld or MapInfo .tab – same name as the picture). JPEG 2000 (.jp2) pictures are converted to TIFF automatically (a large one can take about 10 seconds). MrSID (.sid) cannot be read in a browser: export it from Global Mapper as GeoTIFF first.

ⓘ Select the picture and its world file (.j2w / .tfw) together in one dialog (Ctrl + click). Both are added to the list.
Download TIFF/TFW makes one ZIP with the .tif, .tfw and .prj – unzip and keep them in the same folder.

Combine images

  1. Make each picture in GeoRef Google Image and download it as GeoTIFF (or TIFF + TFW + PRJ).
  2. Here click Choose files and select all the pictures at once. If you use TIFF + TFW, select the .tfw files too (keep the same file names). You can choose more files again to add them.
  3. Use the arrows to set the order. Where two pictures overlap, the one chosen in the box above is on top.
  4. Click Combine, then download the GeoTIFF, or the TIFF + TFW + PRJ.
All pictures must be in the same coordinate system (for example all NY Long Island feet). The result uses the pixel size of the sharpest picture.
Take overlapping views in Google Earth with the same look (same time of day and imagery date) so the joins are not visible.
